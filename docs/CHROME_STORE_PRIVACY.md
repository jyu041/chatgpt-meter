# Chrome Web Store Privacy Mapping

This document is preparation for a future submission; nothing is submitted automatically.

- **Single purpose:** estimate observable historical ChatGPT conversation size and show clearly labeled experimental structural pressure.
- **Host permission:** `https://chatgpt.com/*` is required to observe the open ChatGPT page and use same-origin authenticated requests for older conversation pages.
- **Storage permission:** stores settings and aggregate calibration observations locally.
- **Data sale/sharing:** no sale or sharing of user data.
- **Analytics:** no telemetry or analytics.
- **Remote code:** no remotely hosted executable code, remote configuration, or third-party processing.
- **Developer collection:** no developer-side collection of prompts, replies, tool output, credentials, or conversation text.
