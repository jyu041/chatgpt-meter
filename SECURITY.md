# Security Policy

## Supported Version

The latest stable release is supported. The current beta target is `0.1.0`.

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting feature where available. Do not put authentication tokens, cookies, private conversation content, unredacted network captures, or credential-bearing screenshots in a public issue.

Sanitize any reproduction material before sharing it. Ordinary bugs and non-sensitive feature reports belong in public GitHub issues; sensitive security or privacy disclosures do not.

This project does not publish a dedicated security email address.
